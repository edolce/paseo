# Design audit: workspace row accessory + row takeover

The PR (`43a6a046f`, `56f13c16c` on `main`) checked rule by rule against `docs/design.md`,
`docs/qa.md` ("Does it work well") and CONTRIBUTING ("A finished experience": loading states,
layout stability, interaction performance). Section numbers refer to `docs/design.md`.

Status: **OK** (complies as written), **Fixed** (did not comply; corrected in the commits),
**Accepted** (a trade-off, documented), **Open** (not done; listed in RISKS.md).

## Not changed, by decision

- **Hoisted rows** give their project icon to the accessory; the project name stays in the meta
  line. Alternative considered: keep the icon and put the accessory elsewhere. That would need a
  second slot shape and break the single rail.
- **Rail across all hosts** rather than per project group: a group can mix hosts, and the status
  view mixes everything, so a per-group rail would still misalign.
- **Fade to 0, not 50 %**: at `opacity[50]` the title competes with the Overlay drawn on top of it;
  the takeover is short and the status badge stays.
